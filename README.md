# Лендинг книги «Ваш ребенок — спортсмен»

Одностраничный сайт для продажи книги и записи на консультации авторов.

## Как открыть

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
cd vash-rebenok-sportsmen
python3 -m http.server 8080
```

Затем: http://localhost:8080

## Что редактировать

### 1. Ссылки Telegram и e-mail

В начале `index.html` — блок `window.SITE`:

```js
window.SITE = {
  telegramBook: "https://t.me/BOOK_PURCHASE",      // покупка книги
  telegramJulia: "https://t.me/JULIA_BRAVIKOVA",   // Юлия
  telegramEvgenia: "https://t.me/bravik_17",       // Евгения
  email: ""                                        // e-mail (пусто = скрыт)
};
```

### 2. Фотографии

Положите файлы в папку `assets/`:

| Файл | Назначение |
|------|------------|
| `authors-together.jpg` | Совместное фото авторов (hero) |
| `julia.jpg` | Фото Юлии Бравиковой |
| `evgenia.jpg` | Фото Евгении Остапцовой |

Рекомендуемый формат: JPG/WebP, вертикаль ~4:5, ширина от 900–1200 px.

Пока файлов нет — на сайте показываются аккуратные заглушки.

### 3. Тексты

| Что | Где в `index.html` |
|-----|---------------------|
| Текст о книге | блок `#book-text` |
| Регалии Юлии | блок `#julia-bio` |
| Описание Евгении | блок `#evgenia-bio` |
| Заголовки, кнопки | прямо в разметке (есть комментарии) |

### 4. Политика конфиденциальности

Текст в модальном окне `#privacy` — при необходимости замените на финальный.

## Дизайн

Светлый, минималистичный, «дорогой» визуально. Палитра и типографика согласованы с сайтом Евгении Остапцовой (Cormorant Garamond + Manrope, тёплые кремовые тона, терракотовый акцент на кнопках).
